How to read this page

Each orb is one strike at one moment (1, 3 or 5-minute blocks). Bigger orb = more dealer hedging tied to that strike. Yellow = positive (with Gamma: dealers trade against the move there, so price tends to slow, stall or pin). Purple = negative (dealers trade with the move, so price can speed up through it). Candles are 5-minute SPX (or SPY / QQQ) price.

Gamma = dollars dealers must buy or sell for each 1% move. Vanna = how those hedges change when volatility moves 1 point (a big vanna strike matters on volatility crush or spikes). Both = gamma filled, vanna as rings.

Positions from: Open interest = contracts open at the start of the day, read with the simple rule that dealers are long calls and short puts (the same rule the cockpit's Map uses). Today's volume = today's contracts with the same rule. Trades = today's trades by their buy/sell tag: when a customer bought, the dealer sold, so the dealer is short. These three often disagree; when they agree, the level is more trustworthy.

Expiries: Today = same-day options only. Next 7 days = everything expiring tomorrow through 7 days out. All = both. Strikes cover about ±200 SPX points (±2.7% for SPY / QQQ).

Volume profile (right) = contracts traded today at each strike, up to the time on the slider. Orange line = POC (point of control: the busiest strike). Dashed lines = value area (the strikes that hold 70% of the volume). The orange dotted line on the orbs chart = where the POC sat through the day: when it moves, the fight moved. Calls | Puts = blue calls, pink puts. Bull | Bear = green = calls bought + puts sold, red = puts bought + calls sold (by trade tag).

Play replays the day; nothing to the right of the slider is shown, so the replay never peeks ahead. Now jumps to the latest minute (on a live day the page checks for a new minute every 3 seconds; the feed reads the options data once a minute). Block = 1, 3 or 5 minutes per orb column and candle.

This is a positioning read, not a trade signal. The simple dealer rule is an assumption; real dealer books are not public.
